# 攻防术语科普：POC/EXP、0day、C2、APT 与常用安全工具

网络安全攻防领域充满了各种缩写和黑话，POC、EXP、0day、C2、APT……对刚入门的人来说往往一头雾水。这篇文章整理了一份入门向的术语科普，覆盖漏洞利用、基础设施、攻击活动与攻击手段等维度，最后附上渗透测试中常用的工具与信息收集方法。

先从一条最朴素的攻击路径说起：

> 服务 → 端口 → 端口扫描 → 破解

任何系统都对外提供服务，服务监听在端口上，通过端口扫描发现开放的服务，再针对服务进行破解或利用——这几乎是一切入侵的起点。

## 漏洞利用术语

### POC / EXP / Payload

- **POC（Proof of Concept）**：概念验证，用于验证安全漏洞是否存在、能否被利用。
- **EXP（Exploit）**：漏洞利用，指一段有漏洞利用价值的攻击代码，或一个完整的漏洞利用过程。
- **Payload**：攻击载荷，通常指利用 EXP 拿下目标之后，在目标机器上执行的定制代码，包括执行系统命令、建立连接等。

### 漏洞生命周期：0day / 1day / Nday

安全漏洞存在生命周期，大致可以分为几个阶段：

1. 漏洞被发现
2. 漏洞 EXP 信息被披露公布
3. 漏洞具备官方补丁或修复方案

同时也伴生出几个概念：

- **0day**：漏洞信息尚未公布时，此时利用 EXP 基本可以"通杀"。
- **1day**：漏洞信息已被公布，但漏洞没有官方补丁或修复方案，此时利用 EXP 可以入侵大部分系统。
- **Nday**：漏洞已有官方补丁或修复方案，此时利用 EXP 只能入侵那些还没有及时修复的系统。

### CVE 与 CNVD

- **CVE（Common Vulnerabilities & Exposures）**：即通用漏洞披露，是全球漏洞的"百科全书"，建立了跨组织、跨厂商的通用漏洞沟通语言。CVE 由美国 MITRE 公司创立，通过 CNA（CVE Numbering Authority）机构分配漏洞编号，通过 CVSS 系统评估漏洞等级。
- **CNVD**：全称国家信息安全漏洞共享平台，由国家互联网应急中心（CNCERT）联合国内重要信息系统单位、基础电信运营商、网络安全厂商、软件厂商和互联网企业建立的国家网络安全漏洞库，收录的各类漏洞会被赋予 CNVD 编号。

### Shell 与 WebShell

- **Shell** 是一个应用程序，连接了用户和 Linux 内核，让用户能够更加高效、安全、低成本地使用 Linux 内核，这就是 Shell 的本质。
- **WebShell** 是以 asp、php、jsp 或 cgi 等网页文件形式存在的一种代码执行环境，主要用于网站、服务器、权限管理等操作。

## 基础设施术语

### C2 服务器

C2 服务器英文全称 Command and Control Server，中文为"命令和控制服务器"，可以理解为攻击者发送控制命令的服务端。

### 内外网与 DMZ 区

DMZ（Demilitarized Zone，隔离区/停火区）位于内网与外网之间，用于放置需要对外提供服务、但又需要与内网隔离的服务器（如 Web 服务器、邮件服务器）。即使 DMZ 中的机器被攻破，也能把威胁限制在隔离区内，降低对内网的直接影响。

### 代理

网络安全领域的 Proxy（代理）通常用于两个目的：

- **身份隐藏**：攻击者通过第三方代理服务器访问目标系统，隐藏自己的真实 IP 地址，让别人无法查找到自己。
- **端口转发**：通过代理软件穿透内网限制，访问核心内网服务器。

## 攻击面

- **互联网链路攻击**：所有暴露的互联网应用（Web 应用服务器、数据库服务器、各端口开放服务）
- **社会工程攻击**：鱼叉攻击、鲸钓攻击、水坑攻击
- **近源攻击**：USB 攻击、Wi-Fi 攻击、门禁攻击
- **供应链攻击**：合作伙伴、供应商

## 攻击活动术语

### APT 攻击

APT 中文名为"高级持续性威胁"（Advanced Persistent Threat），通常指处于政治或商业动机，针对特定目标进行的手段高超、低调隐蔽、时间持久、精心策划的攻击。

### 渗透测试

渗透测试（Penetration Testing）是指受信任的第三方通过模拟黑客的攻击技术与手段，对目标网络、系统进行攻击测试，发现目标的安全隐患并给出安全加固建议的一种安全测试与评估方法。

## 攻击手段术语

### 拖库 / 洗库 / 撞库

- **拖库**：攻击者利用漏洞（例如 SQL 注入）入侵网站，把数据库导出到黑客本地服务器的过程。
- **洗库**：攻击者"洗"出账号的价值——如果是金融账号则进行财产转移，如果是游戏账号则盗卖道具或虚拟货币。
- **撞库**：攻击者将收集到的数据库（或社工库）制作成相应的字典表（账号密码），之后尝试批量登录其他网站，"撞"出可以登录使用的账号。

### DoS / DDoS 攻击

- **DoS（拒绝服务攻击）**：利用网络协议缺陷进行攻击，使服务器或网络无法提供正常的服务。
- **DDoS 攻击**：利用控制成百上千台"肉鸡"（傀儡机）组成一个 DDoS 攻击群，在同一时刻对目标主机发起攻击。
- DDoS 攻击主要分为两大类：一类是**带宽消耗型攻击**，例如 UDP 泛洪攻击；一类是**资源消耗型攻击**，例如 CC 攻击（发送大量 HTTP 请求）。

### 钓鱼攻击

入侵者采用社会工程学方法，伪装成可以信任的人或机构，通过**高仿网站、欺诈邮件、虚假短信**等方式，引诱受害者浏览、下载、安装、执行，最终实现对目标对象的入侵和控制。根据不同实施方式，可细分为**鱼叉攻击、鲸钓攻击、水坑攻击**等方式。

### 中间人攻击

中间人（Man-in-the-middle，MITM）攻击，即攻击者置于两台设备之间发起的劫持攻击，可基于 ARP、DNS、HTTP、SSL 等协议，实现会话控制、账号窃取、流量操控（插入、修改、删除）等。

## 安全工具

在进行渗透测试时，根据渗透流程可以将工具分为几类：

| 阶段 | 工具 |
| --- | --- |
| 信息收集 | 爱企查、Google、Shodan、Nmap |
| 漏洞扫描 | AWVS、Nessus |
| 渗透攻击 | Hydra、Metasploit |

### 信息收集

信息收集是指黑客为了更有效地实施渗透攻击，在攻击前或攻击过程中对目标进行的所有探测活动。信息收集的目的是了解**组织安全架构、缩小攻击范围、描绘网络拓扑、建立脆弱点库**。

### 组织架构收集工具

在只知道厂商名的情况下，可以通过这类网站获取企业的**企业规模、投资关系、域名备案、专利、产品、高管**等组织架构信息：爱企查、小蓝本、天眼查、启信宝。

### IT 资产信息收集：Google Hacking

Google Hacking 是利用谷歌搜索的强大功能，在浩瀚的互联网中搜索需要的信息，例如查找网站子域名、网站后台，泄漏文件/文档，寻找网站代码中的相关配置和安全漏洞。常用语法：

| 语法 | 作用 |
| --- | --- |
| `site:` | 限定站点 |
| `intitle:` | 限定标题 |
| `filetype:` | 限定文件类型 |
| `intext:` | 限定正文内容 |
| `inurl:` | 限定 URL 中的关键字 |

### IT 资产信息收集：Shodan

Shodan 用于搜索连接到互联网的设备。与搜索引擎帮你找到网站不同，Shodan 可以帮助你找到路由器、交换机、服务器、IoT 设备等资产的信息，包括元数据，例如每台设备上运行的软件。常用过滤语法：

| 语法 | 作用 |
| --- | --- |
| `hostname:` | 搜索指定的主机或域名 |
| `port:` | 搜索指定的端口或服务 |
| `country:` | 搜索指定的国家 |
| `city:` | 搜索指定的城市 |
| `org:` | 搜索指定的组织或公司 |
| `isp:` | 搜索指定的 ISP 供应商 |
| `product:` | 搜索指定的操作系统/软件/平台 |
| `version:` | 搜索指定的软件版本 |
| `geo:` | 搜索指定的地理位置 |
| `before:` / `after:` | 搜索指定收录时间前后的数据，格式为 dd-mm-yy |
| `net:` | 搜索指定的 IP 或子网 |

## 总结

这篇文章梳理了攻防领域最常用的一批术语和工具：

- 漏洞侧：POC/EXP/Payload、0day/1day/Nday、CVE/CNVD、Shell/WebShell
- 设施侧：C2 服务器、内外网与 DMZ、代理
- 活动与手段：APT、渗透测试、拖库/洗库/撞库、DoS/DDoS、钓鱼、中间人攻击
- 工具链：信息收集（Google Hacking、Shodan、Nmap）→ 漏洞扫描（AWVS、Nessus）→ 渗透攻击（Hydra、Metasploit）

> 本文仅为安全知识科普，请勿用于未授权的系统测试。
